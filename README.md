# Astro Workshop

A feature-rich Astro demo site showcasing:

- 📝 **Blog** – MDX posts with tags, reading time & RSS feed
- 🖼️ **Portfolio** – Filterable project cards
- 🎨 **Components** – Live UI component library
- ✉️ **Contact** – Static-compatible form
- 📡 **RSS Feed** – Auto-generated via @astrojs/rss
- 🗺️ **Sitemap** – Auto-generated via @astrojs/sitemap
- ⚡ **Performance** – Zero JS by default, optimised images

## Deploy

Built for **Cloudflare Pages**:

- Build command: `npm run build`
- Output directory: `dist`

## Local Dev

```bash
npm install
npm run dev
```
